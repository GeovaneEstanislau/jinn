# Contribuindo para Jinn

Obrigado por seu interesse em contribuir para o Jinn. Por favor, siga estas diretrizes básicas:

- Abra Issues para bugs e propostas de features antes de grandes mudanças.
- Fork o repositório e crie branches com nomes descritivos (`feature/`, `fix/`).
- Faça commits pequenos e atômicos com mensagens claras.
- Inclua descrições em inglês e português quando relevante.
- Execute `cargo build --release --target x86_64-unknown-none` antes de enviar PRs.
- Para mudanças de arquitetura (drivers, init, boot), abra uma RFC em `docs/` primeiro.

Agradecemos revisões construtivas e tests quando possível.
